# Product Context

## User Persona
Beginner podcasters who want a simple, reliable way to record video podcasts with a guest without complex setup or technical knowledge.

## Key User Flows
1. **Host Flow**: Sign up → Create session → Share link → Record → Upload → Edit → Export
2. **Guest Flow**: Click link → Join session → Record → Upload (automatic)

## Design Principles
- Minimalist UI with no clutter
- Clear, jargon-free status messages
- One-click guest join, no account needed
- Host-only recording controls
- Simple linear workflow
- Mobile and desktop browser support (Chrome, Edge, Safari)

## Ownership Model
- All sessions, uploads, and episodes are owned by the host account
- Guests never own or manage episode data
- Guests join via token-based links without accounts
